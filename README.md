# Delivery-Risk-Case-Study

Problem Statement : Predicting Delivery Risk at Order Time - Right now, the business only
learns an order will be late after the fact, when a customer complains, or the delivery is already
overdue. Operations wants to move from reactive to proactive: they'd like to know, the moment
an order is placed, whether it carries meaningful risk of arriving late, so they can intervene early,
expedite it, notify the customer ahead of time, or flag it for manual review.
